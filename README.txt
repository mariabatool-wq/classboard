Classboard GitHub Pages + Scriptable

Upload index.html, icon.png, manifest.webmanifest, sw.js to the root of your GitHub Pages repository (replace old files). Do NOT upload this README or Scriptable code to the website unless desired.

In the iPad Scriptable app, open your existing script named exactly Classboard Notifications and replace the test code with the contents of Classboard Notifications.js. Save. Open the Classboard GitHub Pages site in Safari on THAT iPad. Make a reminder, tap Sync Notifications, confirm open Scriptable, and review Scriptable success message. Sync again after any edit or deletion.

Reminders live in the browser storage on each device. Scriptable schedules only future alerts, up to 56 at a time across roughly 30 days. Re-sync later for repeating schedules. Scriptable must be installed, and notification permissions enabled. Background delivery timing is determined by iPadOS.
